🔑 What you'll learn
• git log and the four parts of a log entry
• git log --oneline, -n, --reverse, --stat and -p
• git show with a commit ID, HEAD~1 and HEAD~1:file
• Searching history with --author, --grep and -- file
• git commit --amend -m to fix a commit message
• git commit --amend --no-edit to add a forgotten file
• What amend does inside Git (new commit, same parent) and git reflog
• Why you never amend a pushed commit, and how to fix forward
• DevOps: commit IDs, Jenkins builds and traceability

🧾 Cheat sheet (copy & practice)
git log
git log --oneline
git log --oneline -n 2
git log --stat -1
git log -p -1
git show c5fefa4
git show HEAD~1:app.py
git log --oneline --grep="payment"
git log --oneline -- app.py
git commit --amend -m "Fix login bug"
git commit --amend --no-edit
git reflog
