🔑 What you'll learn
• The 3 areas of Git: working directory, staging area (index), repository
• git status and the short format git status -s
• git add <file> and git add .
• git commit -m and what the output means
• git diff vs git diff --staged
• git commit -am and why it skips new files
• git rm --cached to unstage a file without deleting it
• What add and commit do inside .git
• DevOps: small focused commits for easy review and safe rollbacks

🧾 Cheat sheet (copy & practice)
git status
git status -s
git add app.py
git add .
git commit -m "Add app.py"
git log --oneline
git diff
git diff --staged
git commit -am "Print v3"
git rm --cached .env
git ls-files --stage
